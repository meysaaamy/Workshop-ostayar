# خواندن محدود بکاپ JSON قدیمی

`LegacyBackupReader` در `data/` یک خوانندهٔ مستقل Kotlin برای شناسایی اولیهٔ بکاپ متنی قدیمی است. پاکت‌های خروجی قدیمی `app=stayar` و `version=2` برای full و project و نیز ساختار خام دارای `projects` یا `users` را می‌خواند. اعداد به صورت رشتهٔ JSON اصلی نگه داشته می‌شوند؛ مقدار ساعت `1.2500` و کلیدهای ناشناخته هنگام خواندن از بین نمی‌روند. دریافت mode به عهدهٔ فراخواننده است. این تنها شناسایی شکل و parsing است؛ خروجی آن **اعتبارسنجی، نرمال‌سازی، ذخیره یا بازیابی نشده است**.

دو fixture موجود `parity/golden/backup-{full,project}.json` با اجرای خود توابع export داخل APK، با state و ساعت و مقصد ساختگی و ثابت، تولید شده‌اند. بازتولید آنها با `cd parity && npm run backups-golden` و بررسی با `npm test` انجام می‌شود. این نمونه‌ها بکاپ واقعی کاربر یا آزمون دستگاه نیستند.

## محافظ‌ها و تفاوت‌های عمدی با ورودی قدیمی

خواننده ورودی بالای ۶۴ MiB، UTF-8 نامعتبر، عمق بیش از ۱۲۸، بیش از یک میلیون گره، عدد با بیش از ۱۲۸ نویسه، کلید JSON تکراری، surrogate منفرد و پاکت با شناسه/نوع/نسخهٔ ناشناخته را رد می‌کند. JSON.parse قدیمی بعضی از این موارد از جمله کلیدهای تکراری یا surrogate منفرد را می‌پذیرد؛ این محدودیت‌های محافظه‌کارانه انحراف‌اند و ممکن است فایل قدیمی غیرمعمول را رد کنند. چنین فایلی نباید به‌طور خاموش اصلاح یا حذف شود؛ سیاست و مسیر بازیابی آن هنوز تعیین نشده است. حجم و تعداد گره‌های مجاز همچنین ممکن است برخی بکاپ‌های بزرگ معتبر قدیمی را رد کند؛ پیش از عرضه لازم است با حداکثر اندازهٔ واقعی و راهکار streaming بازبینی شوند. در حال حاضر ورودی `ByteArray` است، پس فراخواننده باید **پیش از تخصیص** خواندن فایل را محدود کند. parser محافظت جامع در برابر کمبود حافظه یا همهٔ داده‌های خصمانه را تضمین نمی‌کند.

`version` پاکت و `state.version` متفاوت‌اند؛ این کد صرفاً نسخهٔ پاکت شناخته‌شده را بررسی می‌کند و اصلاح قدیمی ضریب ۱٫۴، `normalizeState`، کپی امن و validator را اجرا نمی‌کند. خواندن بکاپ تازه، رمزنگاری، SAF، import پروژه، بازگشت در شکست، Room/DataStore و آزمون دستگاه باقی‌اند. نباید خروجی این خواننده را مستقیماً جایگزین دادهٔ کاربر کرد.

```sh
JAVA_HOME=/path/to/jdk KOTLINC=/path/to/kotlinc parity/tools/check-backup-reader.sh
cd parity && npm ci && npm test
```
