# استایار

بازنویسی آفلاین برنامهٔ قدیمی در حال توسعه است و **هنوز برای استفاده یا جایگزینی نسخهٔ نصب‌شده آماده نیست**.

- `domain/`: محاسبات و مدل‌های خالص Kotlin با آزمون همارزی محدود.
- `data/`: اجزای آزمایشی تبدیل، بکاپ و CSV و یک Room دفتر جداگانه؛ migration واقعی هنوز پیاده‌سازی نشده است.
- `app/`: پوستهٔ آزمایشی Compose، بدون قابلیت عملیاتی یا دسترسی به دادهٔ قدیمی.
- `parity/` و `docs/`: آزمون‌های APK قدیمی، goldenها و گزارش پیشرفت و محدودیت‌ها.

جزئیات شرایط ساخت و هشدار نصب در [گزارش اسکلت اندروید](docs/android-scaffold-fa.md) آمده است. گزارش آزمون موتور در [financial-parity-fa.md](docs/financial-parity-fa.md) قرار دارد.
